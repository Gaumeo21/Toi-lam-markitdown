MarkItDown Local Portable
=========================

Run instructions
----------------
1. Extract this ZIP to a normal folder. Paths with spaces are supported.
2. Double-click "Start MarkItDown Local.cmd".
3. Your browser will open the local Streamlit app, or the command window will show a local URL you can copy.
4. Drop one local file, click "Convert to Markdown", preview the output, then click "Download Markdown".

You do not need to install Python, run pip install, create a virtual environment, or run python.exe directly.

Supported local formats
-----------------------
- PDF: .pdf
- Word: .docx
- PowerPoint: .pptx
- Excel: .xlsx, .xls
- Text/Markdown: .txt, .md
- Web/text data files: .html, .htm, .csv, .json, .xml
- Images: .png, .jpg, .jpeg
- ZIP archives: .zip

Not supported
-------------
- YouTube URLs
- Web URLs
- Remote URLs
- Audio files
- Streaming input/stdin

Audio files such as .mp3, .wav, .m4a, .flac, .ogg, .aac, and .wma are rejected before conversion.

Privacy and security
--------------------
This app runs locally and is local-only by default. Uploaded file bytes are written to a temporary file for conversion and deleted after conversion. Convert only files you trust, or run the app in an isolated environment for files from untrusted sources. Do not enable plugins unless you trust the plugins bundled or installed with this portable app.

Troubleshooting
---------------
Keep the command window open if the app fails; it contains error messages that can help diagnose missing files or dependencies.
